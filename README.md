# Adaptive AI Difficulty System

A 3D Souls-like game built in **Unreal Engine 5.4** with a dynamic difficulty adjustment system that adapts to the player's skill level in real-time.

## Overview

This was my dissertation project for BSc Game Software Engineering at Bournemouth University. The goal was to explore how adaptive AI can improve player engagement by tailoring difficulty to individual skill levels — emulating the feel of MOBA and shooter matchmaking dynamics in a single-player context.

## Features

- **Dynamic Scoring System** — Tracks player performance metrics (accuracy, deaths, reaction time, damage dealt/taken) to calculate a real-time skill rating
- **Adaptive AI Behaviour** — Enemy AI adjusts its aggression, attack speed, damage output, and ability usage based on the player's assessed skill level
- **Smooth Difficulty Curves** — Gradual transitions between difficulty tiers to avoid jarring changes mid-gameplay
- **Souls-like Combat** — Lock-on targeting, dodge rolling, stamina management, and pattern-based enemy attacks

## Tech Stack

- **Engine:** Unreal Engine 5.4
- **Language:** C++
- **AI:** Behaviour Trees, Blackboard, custom scoring algorithms

## Results

- Achieved a **20% improvement in player engagement** during user testing compared to static difficulty
- Players reported more satisfying combat encounters across varying skill levels
